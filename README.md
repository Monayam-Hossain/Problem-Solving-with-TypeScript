# TypeScript Assignment – Problem Solving & OOP

## Overview

This repository contains TypeScript solutions covering basic types, optional parameters, readonly tuples, union types, type narrowing, interfaces, generics, asynchronous Promises, and object-oriented programming.

The `solutions.ts` file contains the eight coding-task solutions. The blog articles explain the TypeScript's basic topics, with practical examples and conclusions.

## TypeScript Coding Solutions

- [`solutions.ts`](./solutions.ts) — implementations of `multiplyValue`, `processInput`, `formatCoordinate`, `concatenateArrays`, `getPopularCourses`, `pluckValues`, the `Employee` and `Manager` classes, and `validateAgeAsync`.
